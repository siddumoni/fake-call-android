## Toolchain rationale

- AGP 9.3.1 and Gradle 9.7.0 are the upper versions listed as fully supported by the Kotlin compatibility matrix for KGP 2.4.20–2.4.21.
- Kotlin / Compose compiler plugin: 2.4.21.
- Compose BOM: 2026.11.01, the latest stable BOM documented by Android on 2026-11-26; it selects Compose 1.13.0 and Material3 1.5.0.
- AndroidX Core 1.19.1; Activity Compose 1.13.0; Lifecycle 2.11.1; Preferences DataStore 1.3.0; ktlint Gradle plugin 14.2.0.
- compileSdk / targetSdk 37, minSdk 34, JDK 17.
- AGP 9.5.0 and Gradle 9.9.2 are newer stable releases but exceed the Kotlin 2.4.21 fully-supported AGP / Gradle range. The project prioritizes a documented compatible combination over unverified version maximization.
