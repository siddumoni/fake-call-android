## Toolchain rationale

- AGP 9.3.1 and Gradle 9.7.0 are the upper versions listed as fully supported by the Kotlin compatibility matrix for KGP 2.4.20–2.4.21.
- Kotlin / Compose compiler plugin: 2.4.21.
- Compose BOM 2026.09.00 is the latest stable BOM currently specified in Android's official Compose setup guide. It maps stable Compose 1.12.1, which requires compileSdk 37 and AGP 9.1.1 or newer.
- Compose BOM 2026.11.01 was tested and rejected: it selects Compose 1.13.0, which fails AAR metadata checks unless compileSdk is 37.1. The project must remain at compileSdk 37 per requirement.
- AndroidX Core 1.19.1; Activity Compose 1.13.0; Lifecycle 2.11.1; Preferences DataStore 1.3.0; ktlint Gradle plugin 14.2.0.
- compileSdk / targetSdk 37, minSdk 34, JDK 17.
